# 1. Soal Poin Game

## Pseudocode

```text
ALGORITMA PoinGame
DEKLARASI
    poin, total: integer

DESKRIPSI
    total <- 0
    input(poin)

    while poin != 0 do
        total <- total + poin
        input(poin)
    end while

    output(total)
```

## Kode Go (Golang)

```go
package main

import "fmt"

func main() {
    var poin, total int
    total = 0

    fmt.Scan(&poin)

    for poin != 0 {
        total += poin
        fmt.Scan(&poin)
    }

    fmt.Println(total)
}
```

## Penjelasan
Program membaca poin satu per satu dan menjumlahkannya selama nilai yang dimasukkan bukan `0`. Angka `0` menjadi penanda akhir masukan dan tidak ikut dijumlahkan.

### Contoh
**Masukan**
```text
50
30
-20
10
0
```

**Keluaran**
```text
70
```

# 2. Soal Kuadrat Digit

## Pseudocode

```text
ALGORITMA KuadratDigit
DEKLARASI
    X, digit, kuadrat, total: integer

DESKRIPSI
    input(X)
    total <- 0

    while X > 0 do
        digit <- X mod 10
        kuadrat <- digit * digit
        output(kuadrat, " ")
        total <- total + kuadrat
        X <- X div 10
    end while

    output(baris_baru)
    output(total)
```

## Kode Go (Golang)

```go
package main

import "fmt"

func main() {
    var x int
    fmt.Scan(&x)

    total := 0
    pertama := true

    for x > 0 {
        digit := x % 10
        kuadrat := digit * digit

        if !pertama {
            fmt.Print(" ")
        }
        fmt.Print(kuadrat)
        pertama = false

        total += kuadrat
        x /= 10
    }

    fmt.Println()
    fmt.Println(total)
}
```

## Penjelasan
Digit paling kanan diambil dengan operasi `% 10`, kemudian dikuadratkan. Setelah itu, digit tersebut dihilangkan menggunakan pembagian bulat `/= 10`. Proses dilakukan sampai nilai `x` menjadi `0`. Hasil kuadrat ditampilkan mulai dari digit paling kanan, lalu total seluruh kuadrat ditampilkan pada baris kedua.

### Contoh
**Masukan**
```text
123
```

**Keluaran**
```text
9 4 1
14
```

# 3. Soal Donat

## Pseudocode

```text
ALGORITMA HitungDonat
DEKLARASI
    n, m, x, y, jumlah: integer

DESKRIPSI
    input(n, m, x, y)
    jumlah <- 0

    while n >= x AND m >= y do
        n <- n - x
        m <- m - y
        jumlah <- jumlah + 1
    end while

    output(jumlah)
```

## Kode Go (Golang)

```go
package main

import "fmt"

func main() {
    var n, m, x, y int
    fmt.Scan(&n, &m, &x, &y)

    jumlah := 0

    for n >= x && m >= y {
        n -= x
        m -= y
        jumlah++
    }

    fmt.Println(jumlah)
}
```

## Penjelasan
Program membuat donat selama tepung dan telur masih mencukupi. Setiap satu donat dibuat, persediaan tepung dikurangi `x` gram dan telur dikurangi `y` butir. Perulangan berhenti ketika salah satu bahan tidak cukup.

### Contoh
**Masukan**
```text
500 12 100 2
```

**Keluaran**
```text
5
```

# 4. Soal Bilangan Cantik

## Pseudocode

```text
ALGORITMA BilanganCantik
DEKLARASI
    X, digitKanan, digitKiri: integer
    cantik: boolean

DESKRIPSI
    input(X)
    cantik <- true

    while X >= 10 AND cantik = true do
        digitKanan <- X mod 10
        digitKiri <- (X div 10) mod 10

        if digitKiri > digitKanan then
            cantik <- false
        end if

        X <- X div 10
    end while

    output(cantik)
```

## Kode Go (Golang)

```go
package main

import "fmt"

func main() {
    var x int
    fmt.Scan(&x)

    cantik := true

    for x >= 10 && cantik {
        digitKanan := x % 10
        digitKiri := (x / 10) % 10

        if digitKiri > digitKanan {
            cantik = false
        }

        x /= 10
    }

    fmt.Println(cantik)
}
```

## Penjelasan
Program membandingkan setiap digit dengan digit di sebelah kanannya. Jika digit di sebelah kiri lebih besar daripada digit di sebelah kanan, urutan digit menurun sehingga bilangan bukan bilangan cantik. Jika tidak ada pasangan digit yang menurun, hasilnya `true`.

### Contoh 1
**Masukan**
```text
1234
```

**Keluaran**
```text
true
```

### Contoh 2
**Masukan**
```text
4321
```

**Keluaran**
```text
false
```

# 5. Soal Kapasitas Gudang

## Pseudocode

```text
ALGORITMA KapasitasGudang
DEKLARASI
    K, V, total, i: integer
    penuh: boolean

DESKRIPSI
    input(K)
    total <- 0

    for i <- 1 to 5 do
        input(V)
        total <- total + V

        if total >= K then
            penuh <- true
        else
            penuh <- false
        end if

        output(penuh)
    end for
```

## Kode Go (Golang)

```go
package main

import "fmt"

func main() {
    var k int
    fmt.Scan(&k)

    total := 0

    for i := 1; i <= 5; i++ {
        var v int
        fmt.Scan(&v)

        total += v
        penuh := total >= k
        fmt.Println(penuh)
    }
}
```

## Penjelasan
Gudang dimulai dengan total barang `0`. Program membaca lima pengiriman. Setiap pengiriman ditambahkan ke total, lalu total dibandingkan dengan kapasitas gudang. Program menampilkan `true` jika total sudah mencapai atau melebihi kapasitas, dan `false` jika belum.

### Contoh
**Masukan**
```text
100
30
40
20
15
10
```

**Keluaran**
```text
false
false
false
true
true
```

Kelima soal diselesaikan dengan struktur perulangan yang sesuai.
